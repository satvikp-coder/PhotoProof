# media/

Repository-managed images stored through **Git LFS** (`git lfs install` once).

| Directory | Contents |
|---|---|
| `branding/` | Logos and icons owned by the project |
| `examples/` | Small demonstration images that the project has the right to redistribute |
| `datasets/` | Instructions only. Datasets are downloaded locally and never committed |

Never add user-uploaded photographs or images whose licence does not permit
redistribution.
