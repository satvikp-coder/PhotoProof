# Contributing to PhotoProof

1. Create a virtual environment and install `requirements-dev.txt`.
2. Run `pytest` before opening a change.
3. Keep image datasets, user photographs, model weights, and generated reports out of Git unless there is a clear license and project reason to include them.
4. Add tests for new image-processing behaviour and invalid inputs.
5. When introducing a forensic technique, document assumptions, failure modes, and how it will be evaluated.
6. Do not describe a visualization as conclusive proof of forgery.
